# island_habitat_loss_rates

R code and data for calculating and comparing human-driven habitat loss rates across islands, using global and local proxies, against pre-human baseline loss rates (sea-level rise since the Last Glacial Maximum, and volcanic activity).

## Contents

- **`1_processing.R`**: all habitat-loss (HL) and habitat-loss-rate (HLr) calculations, including calibration of the global and local proxies.
- **`2_statistics_visualization.R`**: summary statistics, statistical tests, and all figures.
- **`input_data/`**: all source files used by the pipeline.
- **`output_data/`**: all data files and figures produced by the two scripts.
